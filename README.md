# MORSE 加密工具

把英文字母轉換成二進位加密格式的網頁小工具。輸入英文，即時轉出一串 0 和 1；也能把二進位貼回去，還原成原本的文字。支援 TXT / PDF 匯出。

> ⚠️ 這是給學習與趣味用的編碼，不是真正的加密。轉換規則是公開可逆的，任何人拿到二進位都能還原，別用它保護重要機密。

## 線上使用

部署在 GitHub Pages：<https://ryanchiu623-wq.github.io/ryanchiu/>

## 功能

- **加密**：輸入英文（區分大小寫、可含空格），即時轉成二進位
- **解密**：貼上二進位，還原成文字
- **複製 / 匯出**：一鍵複製二進位，或下載成 TXT、PDF
- **說明視窗**：點「了解更多」看轉換原理
- Matrix 數字雨背景動畫

## 轉換原理

先把字母對照摩斯電碼，再把摩斯轉成數字（點 = 1、劃 = 3），最後換算成二進位。

| 字元 | 摩斯 | 數字 | 二進位 |
|------|------|------|--------|
| `A` | `·−` | `13` | `1101` |
| `S` | `···` | `111` | `1101111` |

**大小寫**：小寫字母在數字前面多加一個 `9` 當標記。因為字母本身只會用到 1 和 3，9 開頭不會跟大寫撞號，所以解密時能正確還原大小寫。

| 字元 | 數字 |
|------|------|
| 大寫 `A` | `13` |
| 小寫 `a` | `913` |

**空格**：用專屬編號 `7`（二進位 `111`）表示，所以整句話含空格都能原樣還原。

## 開發

純靜態網頁，單一 `index.html`，沒有建置步驟。用瀏覽器直接打開就能跑，或用任何靜態伺服器：

```bash
python3 -m http.server
```

外部函式庫只有 jsPDF（供 PDF 匯出），從 CDN 載入。

### 除錯面板

網址後面加上 `?debug` 會在左下角顯示除錯面板，即時顯示捲動位置，並可切換平滑捲動、Matrix 動畫、毛玻璃效果，方便排查行動版的顯示問題：

```
https://ryanchiu623-wq.github.io/ryanchiu/?debug
```
